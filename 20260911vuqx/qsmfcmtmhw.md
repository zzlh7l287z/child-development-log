# 【通知公告】鱼台县妇幼保健院预防接种门诊3月27日正式接种公告

> 更新时间：2026-09-11 (UTC+8)

**尊敬的居民朋友们：**大家好！为了方便广大居民进行预防接种，提高全民健康水平，**鱼台县妇幼保健院预防接种门诊/狂犬病暴露预防处置门诊在3月27日正式接种****啦！**
****

**科室简介**

**我们的预防接种门诊拥有专业的医疗团队，严格按照国家卫生健康委的相关规定进行操作。我们将竭诚为您提供安全、高效、便捷的预防接种服务。**

预防接种门诊位于门诊楼二楼东，是集计划免疫和儿童保健服务于一体的科室。配备有数字化预防接种门诊信息管理系统，家长可通过引导式的服务流程完成预防接种，只需取一次号，便可享受排队取号、登记、接种、留观数字化一站式服务。数字化系统建立连续性儿童预防接种的服务档案，实现疫苗来源可查、去向可追，进一步确保了接种安全，提升接种服务质量。

**接种服务内容**

1、儿童免疫规划疫苗包括：乙肝疫苗、卡介苗、脊灰灭活疫苗、二价脊灰疫苗、百白破疫苗、白破疫苗、麻腮风疫苗、A群流脑多糖疫苗、A群C群流脑多糖疫苗、乙脑减毒活疫苗、甲肝减毒活疫苗。

2、非免疫规划疫苗包括：水痘减毒活疫苗、乙肝疫苗、口服五价轮状病毒减毒活疫苗、肠道病毒71型灭活(EV71)疫苗、b型流感嗜血杆菌结合疫苗、九价人乳头瘤病毒疫苗等。接种疫苗的种类，会随居民需求逐步丰富，尽可能满足大家的需要，欢迎前来咨询接种。

3. 健康咨询与指导：提供专业的健康咨询与指导，帮助您了解各类疫苗的接种时间和注意事项。

****

**注意事项**

1. 请需要接种的成人携带身份证、儿童携带预防接种证前来就诊。

2. 接种当天请保持良好作息，避免过度劳累。

3. 接种后请在现场观察30分钟，如有不适请及时告知工作人员。

4. 接种后可能出现轻微发热、红肿等反应，属于正常现象，如有疑问可随时咨询我们的医生。
