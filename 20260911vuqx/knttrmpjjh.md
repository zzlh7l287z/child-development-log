# 【妇儿医讯】广州妇儿中心PICU成功救治2名误服“毒鼠强”幼儿

> 更新时间：2026-09-11 (UTC+8)

“

**11月12日周日晚上，当大多数家庭还沉浸在其乐融融的周末假日里，广州市妇女儿童医疗中心珠江新城院区PICU却上演了一出和毒药赛跑的惊险剧。**

”

当天下午，3岁玲玲和浩浩（化名）在亲戚家的士多店玩耍，在没有“任何征兆”的情况下，可怕的事情发生了：家长发现孩子突然呕吐并先后倒地，四肢抽搐，急忙上前呼喊，没有回应，孩子的两眼开始发直，嘴唇发紫，家长慌了神，急忙送往广东省第二人民医院就诊，经过常规处理后孩子仍反复抽搐，考虑病情凶险，随即转至广州市妇女儿童医疗中心珠江新城院区急诊科….. 晚上九点半左右两名患儿先后送进PICU救治。

此时，整个ICU弥漫着紧张的气氛，孩子的家长焦灼而惶恐在过道间徘徊，眼神充满了悲伤和期待，他们把唯一的希望寄托在了白衣天使的手里。虽然从家长语无伦次的描述中无法明确到底是什么原因让孩子突然发生抽搐和意识不清，但**经验丰富的医生敏锐地意识到患儿可能是中毒了。**

值班医生郑健斌和护士迅速安置好患儿，二线黄莉主任也回到科室指挥抢救，为患儿接上心电监护，留置气管插管，建立中心静脉管道，完成抽血、洗胃、留取标本等一系列操作，稳定患儿的呼吸和循环状态。**抢救工作在紧张而有条不紊地进行中，每一个环节都把握得及时而有效，这充分体现了PICU医务人员良好的专业素养和临阵不乱的心理素质！**晚上11点，根据科室现有的设备，立即为患儿实施血浆置换治疗，此时此刻，生命在和时间赛跑，也可以说是天使在和毒药赛跑--越是尽早做血液净化，就越能减少毒物在体内的吸收。

血浆置换后的下一步，是继续给患儿行血液灌流治疗，但此时，科室并没有血液灌流必需的碳罐及配套管路，**护士长当机立断，安排护理员立刻打车到儿童院区肾内科借耗材，又以迅雷不及掩耳之势赶回PICU配合抢救。**时间在一分一秒中度过！这是生命延续的时间，也可能是生命流逝的时间，每一分每一秒都是那么的宝贵。

由于面临的是两名患儿突发不明毒物中毒的夜间抢救，**为了确保万无一失，保证每个时间段的人力配备和调度及时有效，本来0:00下班的4名护士仍然坚守工作岗位直到凌晨5点钟，这充分体现了PICU医护人员的集体主义精神和救死扶伤的高贵品质，以及尊重生命、与病魔抗争到底的决心！**PICU是医院守护生命的最后一关，挡住了，就是阳平关；挡不住，就是鬼门关！

11月13日，患儿被确诊为“毒鼠强”中毒（毒鼠强是一种毒性很强的灭鼠药，通常误食后的儿童患者很难抢救存活），病人症状仍在进行性加重，意识不清，抽搐发作更为严重。**面对如此危急的病人，以陶建平主任为首的PICU救治团队密切地监控着两名小病人的病情进展，积极为病人开展保障生命的“血液净化技术”序贯治疗。**PICU医护人员日以继夜地忙碌着，每小时监测瞳孔、体温，时刻关注着监护仪上闪烁的生命体征，进行液体管理、管道护理、气道护理、抽血、输血、参数登记，继续洗胃、导泄、呼吸机辅助呼吸、重要脏器功能支持，维持患儿呼吸、循环和内环境稳定，为抢救生命而努力着。病人血压低了，医生及时调整血液净化血流速度和血管活性药物剂量，每一个细微的指标变化，都在有效的监控范围内，并且做出快速的应对。**训练有素、抢救迅速、配合默契的PICU医护团队协作精神，是我们守护病人生命的有力保障。**

11月15日，经过正确、及时有效的救治后，患儿终于清醒过来，没有再出现呕吐抽搐等症状。两名患儿分别在当天和17日转至普通病房继续治疗。在患儿离开PICU之际，**黄莉主任语重心长地对家属进行了安全教育：作为监护人，一定要看护好孩子，一定要让幼儿在自己视力范围内活动，这次真的是多亏医务人员专业有效的及时抢救，绝大部分吃了毒鼠强的儿童，基本都是死亡的。尽好监护人的责任，不要让遗憾的事情再发生！**

和病魔赛跑的72小时里，充分体现了广州市妇女儿童医疗中心珠江新城院区PICU医务人员的智慧、专业和毅力！尽管很累很辛苦，但能从死神的手中夺回生命，让生命继续绽放美丽的花朵，是每个PICU人的信念和操守！

**知多d：什么是毒鼠强**

化学名称四亚甲基二砜四胺，俗称４２４、三步倒、闻到死。它无臭无味，是一种剧毒物质，其毒性相当于氰化钾的１００倍，５毫克可致成人死亡，１千克可致２０万人死亡，目前尚无特效解毒剂。更为可怕的是，毒鼠强对所有的温血动物都有剧毒，而且具有严重的二次或连续中毒作用。这就是说，老鼠吃了，老鼠死；猫吃毒死的老鼠后，猫死；将毒死的鼠、猫埋在土里，其上面长出的庄稼如果被人食用，人也会中毒甚至死亡。
