# 【每日一方】骨质疏松——沉默的杀手！

> 更新时间：2026-09-16 (UTC+8)

随着人们生活水平的提高，现在“三高”人群也是越来越多，但很多人都知道三高的危害，却不知道除了“三高”，还有个“一低”，那就是低骨量。低骨量，又称骨量低下，是骨量随年龄逐渐丢失的结果。低骨量如果不加以干预，通常数年后可能转变为骨质疏松症。

**襄阳市中心医院内分泌科主任 徐少勇**

**什么是骨质疏松症？**

世界卫生组织（WHO）指出骨质疏松症是一种因骨量下降，骨微结构破坏，导致骨脆性增加，易发生骨折为特性的全身性骨病。
**什么样的人容易患骨质疏松？**

骨质疏松主要见于老年男性和绝经后妇女，我们称为原发性骨质疏松。随着人口老龄化越来越严重，目前我国有超过1000万的男性患者和4000万的女性患者，而骨量减少人群甚至高达2亿。

**患了骨质疏松危险吗？**

骨质疏松不能小瞧，它的危害是很大的，轻则影响生活，比如腰背痛，重则致残致死，它被称为“人生中最后一次骨折”。骨质疏松甚至是比糖尿病、高血压等更严重需要关注的疾病。
**怎样预防和治疗骨质疏松？**

确诊的**骨质疏松**，需要尽快到医院进行治疗。**襄阳市中心医院内分泌科**有专门的骨质疏松门诊叫**“骨质疏松和骨矿盐疾病门诊“**。原发性骨质疏松是年龄相关疾病，可防可控但不可治愈的，目前该科治疗的主要目的是尽可能降低脆性骨折发生风险，对于已经发生脆性骨折的，避免再次发生。治疗包括基础措施和药物治疗，调整生活方式，包括高钙低盐饮食，运动，晒太阳，戒烟限酒，防跌倒等。药物包括补充钙剂、维生素D，抗骨质疏松药物等。还有重要的一点，诊断原发性骨质疏松症之前，应该排除常见的可导致骨质疏松的疾病或原因，也就是要确诊骨质疏松是原发性的还是继发性的，否则可能导致治标不治本。和原发性骨质疏松不一样，一些继发性的骨质疏松，找到了病因，对症治疗，往往会得到治愈。

**没有症状，可否不治疗？**

千万不能忽视骨质疏松，任何阶段治疗都比不治疗好，大部分骨质疏松一开始都是没有症状的，但是一旦发生脆性骨折，后果会很严重，这也是称之为“沉默的杀手”的原因，所以一定要做正规检查，规范用药。
**小编的话**
出现了骨质疏松，千万不要大意，要到医院做正规的检查，找到引发骨质疏松的原因，做到正确治疗和预防。爱护自己的身体，是最基本的自爱。愿你有坚强的心，也有坚强的骨。
